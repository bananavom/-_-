# AAA Selfmarketing Design System v1.0

> AAA팀(셀피쉬클럽) 내부 셀프마케팅용 인스타 캐러셀 · 발표 덱 · 공지 이미지의
> 톤·앤드·매너를 고정하기 위한 디자인 시스템.
>
> 이 스킬은 이 시스템을 그대로 따른다. 스폰지클럽 1기 운영을 위해 마스코트·푸터를 추가 변주했다.

---

## 정체성 (Identity)

- **컬러 3색 고정**
  - Ink `#0A0A0A` (검정, 주 배경 / 본문)
  - Paper `#FFFFFF` (흰색)
  - Yellow `#E9ED12` (포인트 · 하이라이트)
- **타이포**: Pretendard Variable (한글/영문 공통)
- **무드**: 미니멀 · 큰 숫자 · 큰 여백 · 굵은 위계

---

## 레이아웃 카탈로그 (6종)

| 이름 | 용도 |
|---|---|
| `Hero`  | 포스터 훅 — 커버 / 섹션 헤더 / 펀치라인 |
| `Split` | 2열 대비 — Before/After, Do/Don't |
| `Quote` | 후기 / 인용문 |
| `Stats` | 큰 숫자 — 결과 / 임팩트 |
| `List`  | 넘버드 리스트 3~5개 |
| `CTA`   | 마지막 장 — 행동 유도 |

**원칙**: 새 레이아웃을 만들기 전에 6종 중 맞는 게 있는지 먼저 확인.

---

## 절대 원칙 (Rules)

1. **팔레트는 3색.** 다른 색 추가 금지. 회색조차 Ink의 투명도로 표현.
   (단, 마스코트는 별도 변주 채널 — 베이스 슬라이드 색은 3색 유지)
2. **옐로우 배경은 전체 덱의 1~2장만.** 리듬용. 남발 금지.
3. **`.hl` 하이라이트는 한 슬라이드에 1개.**
4. **페이지 번호 / 섹션 마커("— 04 —") 넣지 말 것.**
5. **한 슬라이드 = 한 메시지.** 두 메시지면 두 장으로 쪼개기.
6. **숫자는 크게, 단위는 작게.** (예: `3h` → 3은 거대, h는 작게)
7. **카피는 후킹 먼저 · 설명 나중.**
8. **실제 UI 스크린샷이라도 발표 가독성을 위해 HTML로 재현.**
   (알림톡·슬랙 모달 등. 사용자가 준 스크린샷을 그대로 쓰지 말고 UI를 HTML로 모사)
9. **이모지 · 그라디언트 · 라운드 컨테이너 + 좌측 컬러바 같은 "AI slop"은 쓰지 않는다.**

## 톤 & 보이스 (Voice)

- **구어체 > 문어체.** "그래서 진짜 내 업무에는 어떻게 적용하는데?" 같은 생생한 말투.
- **질문형 훅 선호.** 단정형보단 청중을 끌어당기는 의문형.
- **숫자 · 기간 · 결과를 앞세운다.** "8명이 6주간", "3h → 5min"처럼.
- **겸양어 금지.** "~하시면 어떨까요" 대신 "~합니다".
- **단정형 안에서도 호흡 풀기.** "한다" → "맡긴다", "17시" → "오후 5시" 같은 부드러운 변주 OK.

## 워크플로우 (Workflow)

새 캐러셀 / 덱 요청을 받으면:

1. 주제 · 훅 한 문장 확정
2. 몇 장인지 · 무슨 플로우인지 정리
3. 각 장마다 **어떤 레이아웃(Hero/Split/Quote/Stats/List/CTA)을 쓸지** 먼저 매핑
4. 그 다음에 카피 작성
5. HTML 조립
6. Do/Don't 체크리스트로 자체 검수

---

## 스폰지클럽 1기 변주

마스코트 · 푸터 · 색 순환은 스폰지클럽 1기를 위해 추가된 변주다.
다른 스터디에 적용하려면 `assets/mascots/` 를 본인 그룹 마스코트로 교체.

- **마스코트**: 4색 캐릭터 (Purple/Blue/Orange/Red), 슬라이드 하단 좌측 200×200
- **배치 룰**: 앞 2장 + 뒤 2장에만 마스코트 (총 8장 중 4장)
  - 중간 4장은 메시지에 집중 (Split/Quote/Hero yellow 같은 강조 슬라이드)
- **색 순환**: Purple → Blue → ... → Purple → Blue (시그니처 2색)
- **상단 좌측**: `{브랜드} 1기 · Week NN`
- **하단 우측**: `{조} · {이름}`

## 8장 표준 플로우

이 스킬이 기본으로 제안하는 흐름:

```
1. Hero (white)    — 질문형 후킹 + 첫 인상
2. Stats (ink)     — 결과 숫자
3. List (white)    — 선택지 / 옵션 노출
4. Hero (yellow)   — 핵심 결과물 / 시각 임팩트
5. Split (white)   — 반전 / 비교 / 발견의 순간
6. Quote (ink)     — 가장 큰 깨달음 (1번 질문의 답)
7. List (white)    — 배운 것 3가지
8. CTA (white)     — 콜백 질문 + 다음 단계
```

스토리텔링 호흡: 질문(1) → 결과(2) → 선택(3) → 첫 결과물(4) → 반전(5) → 답(6) → 배움(7) → 콜백 질문(8)

## 자체 검수 체크리스트

발행 전에 모든 슬라이드에 대해 확인:

**Do**
- [ ] 팔레트 3색만 사용
- [ ] 옐로우 배경 1~2장 이내
- [ ] `.hl` 슬라이드당 1개
- [ ] 한 슬라이드 한 메시지
- [ ] 숫자 크게, 단위 작게
- [ ] 카피 후킹 먼저

**Don't**
- [ ] 페이지 번호 / 섹션 마커 없음
- [ ] 이모지 없음 (Hero/CTA에 화살표 1~2개 정도는 OK)
- [ ] 그라디언트 / 라운드 컨테이너 / 좌측 컬러바 없음
- [ ] 겸양어 없음

**톤**
- [ ] 구어체 (~한다 / ~된다 / ~될까)
- [ ] 질문형 훅 (Slide 1, 8)
- [ ] 숫자/기간/결과 앞세움
